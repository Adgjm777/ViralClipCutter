# Viral Clip Cutter

Автоматическая нарезка коротких клипов из длинного видео: находит смысловые границы,
вырезает фрагменты нужной длины, при желании добавляет субтитры и приводит картинку
к вертикальному формату для Reels, Shorts и TikTok.

Работает локально на Windows, без загрузки видео на чужие серверы.

**Язык / Language:** Русский | [English](README.en.md)

---

## Что умеет

- Режет видео по смене сцен или на равные части заданной длины.
- Ограничивает длину клипа: не короче и не длиннее заданных значений.
- Распознаёт речь и делает субтитры (если установлен пакет для распознавания).
- Умное кадрирование: держит главный объект в кадре при переводе в вертикаль.
- Накладывает заголовок и подложку под конкретную площадку.
- Может добавлять фоновую музыку.
- Умеет скачивать исходник по ссылке (YouTube и другие площадки) через yt-dlp.
- Есть графический интерфейс — `gui.py`.
- Пишет отчёт и журнал в папку с результатом.

## Что нужно установить

1. Python 3.10 или новее.
2. ffmpeg — программа для работы с видео. Скачать с https://ffmpeg.org/download.html,
   распаковать и добавить папку `bin` в переменную среды PATH.
   Проверка: откройте командную строку и введите `ffmpeg -version`, должна появиться версия.
3. Библиотеки Python:

```
pip install opencv-python numpy requests
```

Дополнительно, по желанию:

```
pip install yt-dlp
pip install SpeechRecognition
```

- `yt-dlp` нужен, только если видео скачивается по ссылке.
- `SpeechRecognition` нужен, только если нужны субтитры.

## Быстрый старт

```
python viral_clip_cutter.py -i "C:\video\lecture.mp4" -o "C:\video\clips"
```

Результат: папка `C:\video\clips` с готовыми фрагментами и журналом.

Через графический интерфейс:


## Параметры командной строки

| Параметр | Что делает |
|---|---|
| `-i`, `--input` | путь к видео или ссылка (обязательный) |
| `-o`, `--output` | папка для клипов, по умолчанию `clips` |
| `-t`, `--threshold` | чувствительность определения смены сцены |
| `-min` | минимальная длина клипа в секундах |
| `-max` | максимальная длина клипа в секундах |
| `-f`, `--format` | формат и разрешение результата |
| `-T`, `--title` | добавить заголовок на видео |
| `-w`, `--workers` | сколько клипов обрабатывать одновременно |
| `-v`, `--verbose` | подробный вывод в консоль |
| `-e`, `--equal-parts` | резать на равные части |
| `-p`, `--part-duration` | длина равной части в секундах |
| `-s`, `--subtitles` | сделать субтитры по речи |
| `--template` | шаблон оформления: tiktok, instagram и другие из кода |
| `-r`, `--smart-reframe` | умное кадрирование под вертикаль |
| `-m`, `--music` | добавить фоновую музыку |
| `--music-file` | путь к файлу музыки |
| `--preview` | быстрый предпросмотр без полной обработки |
| `--viral-boost` | усиленные настройки под короткие клипы |
| `--auto-fallback` | переключаться на резервный способ, если основной не сработал |
| `--command-timeout` | предел времени на одну команду ffmpeg, в секундах |

Примеры:

```
python viral_clip_cutter.py -i "D:\video\podcast.mp4" -o "D:\clips" -min 15 -max 60
python viral_clip_cutter.py -i "D:\video\webinar.mp4" -o "D:\clips" -e -p 30
python viral_clip_cutter.py -i "D:\video\talk.mp4" -o "D:\clips" -r -f 1080x1920 -s
```

## Частые проблемы

**`ffmpeg не найден`** — ffmpeg не в PATH. Проверьте `ffmpeg -version` в командной строке.

**Кириллица в пути ломает обработку** — положите видео в папку с латинским именем,
например `C:\video\src.mp4`, и туда же пишите результат.

**Клипы слишком рваные** — уменьшите `-t` (чувствительность) или задайте `-e -p`,
чтобы резать на равные куски.

**Субтитры не появляются** — не установлен `SpeechRecognition` или в видео нет речи.

## Ограничения

- Скрипт рассчитан на Windows: часть кода использует системные вызовы Windows.
- Скачивание по ссылке работает через yt-dlp; у некоторых площадок это нарушает их правила,
  ответственность за использование лежит на пользователе.
- Обработка идёт локально, интернет нужен только для скачивания исходника.
